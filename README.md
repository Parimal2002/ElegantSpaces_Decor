# ElegantSpaces Decor

Seven responsive pages built with HTML, CSS and JavaScript. Open index.html or upload all files in this directory to your hosting public_html. No build tools required.

Pages: Home, Studio, Services, Projects, Journal, Contact, Consultation.

IMPORTANT: The consultation form prepares a downloadable enquiry on the visitor’s device. It does not submit, email, save or confirm a booking. Connect a real backend before accepting enquiries online. No account registration is implemented because a consultation does not require an account.

Replace image URLs in the HTML with your own images (the current photos are remote Unsplash concept imagery). Google Fonts and images require an internet connection. System font fallbacks are included. Add your verified phone number, email address and opening hours before launch; placeholder contact details from the original were removed. The original Yavatmal address is used consistently. Prices are personalised, not fictional fixed packages.

Edit colours in style.css :root, and interactions in script.js. Projects filters and mobile navigation work without a backend. Designed by Parimal Chaudhari.
